公平性、安全与合规

源码公开不代表任何地区的上线许可，也不代表项目已经通过安全或公平性认证。

本页目录公平性安全与隐私法律与平台

游戏公平性

不得操纵真实玩家结果、隐瞒赔率或绕过监管。RNG、发牌、机器人行为、管理员权限和结算必须经过独立审查。robotwinrate.* 与 setwincard.* 等高风险组件应有明确合法用途、最小权限、多人审批、不可篡改审计，并在非必要时从生产版本移除。

安全与隐私

实施服务端权威校验、重放防护、幂等、速率限制、加密、密钥轮换、数据最小化、留存与删除策略。对完整 Git 历史进行凭据和个人数据扫描。

法律、支付与平台政策

部署者需要针对赛事、奖品、年龄、地域限制、支付、虚拟资产、税务、隐私、消费者保护、Apple/Google 政策和第三方素材授权获得专业审查。本页面不是法律意见或合规认证。
