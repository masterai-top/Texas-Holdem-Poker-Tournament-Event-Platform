# 常见问题

## 这是完整多人德州扑克系统吗？

公开仓库主要包含 C++/Tars 服务端代码。完整 Unity 客户端、数据库初始化、后台和商业组件需要以实际目录和授权说明为准。

## 是否包含扑克 AI？

仓库存在机器人行动和胜率计算代码，可以描述为机器人逻辑。没有公开基准时，不应宣传为高级或最强 AI。

## 如何下载？

在 [仓库首页](https://github.com/masterai-top/TexasHoldem-Poker-Multiplayer-Source-Code-Pro) 点击 **Code → Download ZIP**。

## 可以直接商业运营吗？

不能仅凭公开仓库判断。必须确认许可证、完整组件、构建状态、安全审计和所在地法律要求。
