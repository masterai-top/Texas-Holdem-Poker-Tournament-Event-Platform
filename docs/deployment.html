发布文档与上线检查

GitHub Pages 只发布静态文档网站，不会部署 C++ 游戏服务，也不会改变仓库地址。

本页目录发布 Pages服务端构建搜索收录

发布 GitHub Pages

  1. 将本包 repository-files/ 内部内容合并到仓库根目录。
  2. 进入 Settings → Pages，将 Source 设为 GitHub Actions。
  3. 推送 main 后，在 Actions 中确认 Deploy GitHub Pages 显示绿色对勾。
  4. 访问项目网站并检查首页、子页面、截图、robots 和 sitemap。

服务端上线前

当前仓库不是可直接上线的完整发行包。先补齐外部依赖和原始协议，完成干净环境构建、自动化测试、秘密扫描、数据库迁移、监控、备份、回滚和公平性审计。

特别核对 robotwinrate.*、setwincard.*、机器人权限、牌面生成、RNG 和结算路径。非必要的结果控制逻辑不得进入生产构建。

搜索收录

Pages 成功后，将站点和 sitemap.xml 提交到 Google Search Console 与 Bing Webmaster Tools。robots、sitemap、结构化数据和内链帮助抓取，但不能保证固定排名；持续发布真实构建、测试、Release 和技术文档更重要。
